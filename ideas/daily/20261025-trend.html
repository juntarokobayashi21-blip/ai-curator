PHP2Shell: Critical RCE Vulnerabilities CVE-2026-109618 & CVE-2026-109619
Web (Fastly / Rapid7 / Wiz / SOC Prime)  セキュリティ
CVSS 9.2の緊急RCE脆弱性がPHPコアに2件。PHP-FPM・Apache mod_php・FrankenPHP全対応環境が影響対象で、Webサービスの約70%が晒されている。NSAが即時パッチまたはオフライン化を勧告。PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35で修正済み。WAFルールで暫定対策も可。

Web (複数メディア)  AI開発

Web  セキュリティ
